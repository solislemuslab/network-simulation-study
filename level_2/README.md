# Level-k robustness study for SNaQ

Goal: This simulation study will investigate the performance of SNaQ when the true network is not level-1.

## Dependencies

- [R](https://www.r-project.org/)
  + [SiPhyNetwork](https://github.com/jjustison/SiPhyNetwork): 
  ```
  install.packages("devtools")
  devtools::install_github("jjustison/SiPhyNetwork")
  ```
  + [ape](https://cran.r-project.org/web/packages/ape/index.html)
  ```
  install.packages("ape")
  ```
- [ms converter](https://github.com/NathanKolbow/msConverter)
```
git clone https://github.com/NathanKolbow/msConverter.git
cd msConverter
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```
  + The executable `ms-converter` will then be located in `build/ms-converter`
  + In Mac, you might need to install `cmake` first: `brew install cmake` using [Homebrew](https://brew.sh/)
  + In Mac, you might also need to install BOOST: `brew install boost`
  + After compiling, copy the executable in your PATH. For example, in Mac, `cp ms-converter /usr/local/bin`
- [ms](http://home.uchicago.edu/~rhudson1/source/mksamples.html), untar the file and compile with `gcc -o ms ms.c streec.c rand2.c -lm`. Note that we use `rand2.c` so that the number generator used is `rand()`, not `drand48()` which is supposed to be inferior.
  + After compiling, copy the executable in your PATH. For example, in Mac, `cp ms /usr/local/bin`

  + The user needs to copy the executable corresponding to their OS in their PATH. For example, in Mac, you can type in the terminal:

## Pipeline

The scripts in this repository should be run in the following order

1. `generate_datasets.R`: This script simulates networks using `SiPhyNetworks` under the birth-death-hybridization model and then, simulates gene trees on every network using `ms` under the multispecies coalescent model. The script relies on the `ms-converter` executable to convert the parenthetical format to the ms format.
  - **Input:** We need to specify the following parameters in the script directly:
    - Number of networks (numbsim)
    - Number of leaves in the network (ntips)
    - Speciation rate (lambda), fixed for all cases
    - Extinction rate (mu), fixed for all cases
    - Hybridization rate (nu)
    - Proportion of each type of hybridization (hybprops), fixed for all cases
    - Number of gene trees (ngt)
    - Number of replicates per simulation scenario (gt_replics)
    - Global seed
  - **Output:** The script produces one folder per (network, gene trees) pair. The output folder has the name `network1_ntips_15_nu_0.02_ngt_100_rep_1` where `network1` corresponds to the first simulated network (out of the numbsim specified), `ntips, nu, ngt` correspond to the parameters that vary in the simulations, and `rep_1` corresponds to the first replicate of this simulation scenario (out of gt_replics).
```{bash}
Rscript -f generate_datasets.R
```



2. `cfs_and_starting_tree.jl`: This script will take as input the gene-tree file generated by hybrid-Lambda, and then will use PhyloNetworks for calculation of the concordance factor table, writing it to a file. Then it will use TICR's get-pop-tree.pl in order to calculate a starting tree using quartets, writing it to a file. It takes a single argument, the path to the gene-tree file from hybrid-Lambda.

```{bash}
julia cfs_and_starting_tree.jl path-to-genetrees-file.hybridlambda
```

3. `network_estimation.jl`

This script takes five arguments, which are in their respective order:

- cf_table: The path to the CSV file containing the CFs
- init_tree: the path to the initial tree, for instance from an analysis using maximum likelihood, get-pop-tree.pl, or a previous run of SNaQ, in whose .out file we have a tree.
- h: The maximum h in the iteration
- nruns: Number of parallel runs to be carried out
- seed: the random seed

```{bash}
julia network_estimation.jl cf_table init_tree h nruns seed
```


- `get-pop-tree`: Julia implementation of the TICR perl script [`get-pop-tree.pl`](https://github.com/nstenz/TICR/blob/master/scripts/get-pop-tree.pl) that runs Quartet MaxCut.
