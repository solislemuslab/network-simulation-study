## Pipeline

The scripts in this repository should be run in the following order

1. `generate_datasets.R`: This script will bla bla bla. This script itself calls `extnewick2hybridlambda.jl` as the engine of format conversion between extended newick and hybrid-Lambda's specific network format.

```{bash}
Rscript -f generate_datasets.R
```

2. `cfs_and_starting_tree.jl`: This script will take as input the gene-tree file generated by hybrid-Lambda, and then will use PhyloNetworks for calculation of the concordance factor table, writing it to a file. Then it will use TICR's get-pop-tree.pl in order to calculate a starting tree using quartets, writing it to a file. It takes a single argument, the path to the gene-tree file from hybrid-Lambda.

```{bash}
julia cfs_and_starting_tree.jl path-to-genetrees-file.hybridlambda
```

3. `network_estimation.jl`

This script takes five arguments, which are in their respective order:

- cf_table: The path to the CSV file containing the CFs
- init_tree: the path to the initial tree, for instance from an analysis using maximum likelihood, get-pop-tree.pl, or a previous run of SNaQ, in whose .out file we have a tree.
- h: The maximum h in the iteration
- nruns: Number of parallel runs to be carried out
- seed: the random seed

```{bash}
julia network_estimation.jl cf_table init_tree h nruns seed
```
