# Level-k robustness study for SNaQ

Goal: This simulation study will investigate the performance of SNaQ when the true network is not level-1.

## Dependencies

- [R](https://www.r-project.org/)
  + [SiPhyNetwork](https://github.com/jjustison/SiPhyNetwork): 
  ```
  install.packages("devtools")
  devtools::install_github("jjustison/SiPhyNetwork")
  ```
  + [ape](https://cran.r-project.org/web/packages/ape/index.html)
  ```
  install.packages("ape")
  ```
- [Quartet MaxCut](https://citeseerx.ist.psu.edu/viewdoc/download?doi=10.1.1.724.3735&rep=rep1&type=pdf). Note that we cannot find the tar file online anymore. We include a version of the QMC code [here](https://github.com/solislemuslab/network-simulation-study/tree/master/level_2/pipeline/get-pop-tree/QMCN).
  + The user needs to copy the executable corresponding to their OS in their PATH. For example, in Mac, you can type in the terminal:
  ```
  cd network-simulation-study/level_2/pipeline/get-pop-tree/QMCN
  cp find-cut-Mac /usr/local/bin
  ```
- [Julia](https://julialang.org/downloads/)
  + [PhyloNetworks](https://github.com/crsl4/PhyloNetworks.jl) with `] add PhyloNetworks`
  + [PhyloPlots](https://github.com/cecileane/PhyloPlots.jl) with `] add PhyloPlots`
  + [PhyloCoalSimulations](https://github.com/cecileane/PhyloCoalSimulations.jl) with `] add PhyloCoalSimulations`
  + CSV (dependency of PhyloNetworks, so no need to install separately)
  + Distributed (dependency of PhyloNetworks, so no need to install separately)
  + DataFrames (dependency of PhyloNetworks, so no need to install separately)
- [`get-pop-tree.pl`](https://github.com/nstenz/TICR/blob/master/scripts/get-pop-tree.pl) from the [TICR pipeline](https://github.com/nstenz/TICR). This file needs to be in the PATH.

## Pipeline

The scripts in this repository should be run in the following order

1. `generate_datasets.R`: This script simulates networks using `SiPhyNetworks` under the birth-death-hybridization model and then, simulates gene trees on every network using `PhyloCoalSimulations` by running the script `sim_gts_calc_cf_startingtree.jl` at the end.
  - **Input:** We need to specify the following parameters in the script directly:
    - Number of networks (numbsim)
    - Number of leaves in the network (ntips)
    - Speciation rate (lambda), fixed for all cases
    - Extinction rate (mu), fixed for all cases
    - Hybridization rate (nu)
    - Proportion of each type of hybridization (hybprops), fixed for all cases
    - Number of gene trees (ngt)
    - Number of replicates per simulation scenario (gt_replics)
    - Global seed
  - **Output:** The script produces one folder per (network, gene trees) pair. The output folder has the name `net1_ntips_15_nu_0.02_ngt_100_rep_1` where `net1` corresponds to the first simulated network (out of the numbsim specified), `ntips, nu, ngt` correspond to the parameters that vary in the simulations, and `rep_1` corresponds to the first replicate of this simulation scenario (out of gt_replics).
  - **Usage:**
  ```{bash}
  Rscript -f generate_datasets.R
  ```
  - `sim_gts_calc_cf_startingtree.jl`: This script will take as input the networks generated by `generate_datasets.R` and use `PhyloCoalSimulations.jl` for simulating the gene trees using the path to each network, and the `nsims` argument which specifies how many gene trees to simulate, and then will use PhyloNetworks for calculation of the concordance factor table, writing it to a file. Then it will use TICR's `get-pop-tree.pl` in order to calculate a starting tree using quartets, writing it to a file. It takes two arguments, the path to the gene-tree file and the number of simulations (`gt_replics`). This is called internally by `generate_datasets.R` and thus there is no need to call it explicitly. Part of the TICR pipeline, it is a perl script [`get-pop-tree.pl`](https://github.com/nstenz/TICR/blob/master/scripts/get-pop-tree.pl) that runs Quartet MaxCut.

3. `network_estimation.jl`: This script takes five arguments, which are in their respective order:
- cf_table: The path to the CSV file containing the CFs
- init_tree: the path to the initial tree, for instance from an analysis using maximum likelihood, `get-pop-tree.pl`, or a previous run of SNaQ, in whose .out file we have a tree.
- h: The maximum h in the iteration
- nruns: Number of parallel runs to be carried out
- seed: the random seed

```{bash}
julia network_estimation.jl cf_table init_tree h nruns seed
```
